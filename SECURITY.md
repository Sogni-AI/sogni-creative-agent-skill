# Reporting a vulnerability

Please report security issues privately by email to app@sogni.ai. Do not open a public GitHub issue, pull request or discussion for them.

Please include:

- the repository and the package version or commit, or the sogni.ai page or API endpoint, that is affected
- what you found and what it allows
- the steps or a minimal proof of concept to reproduce it

Please give us reasonable time to fix an issue before you disclose it publicly. While you research, do not access other people's accounts or data, run tests that degrade the service for others, or spend funds or credits that are not yours.

We will acknowledge your report and keep you informed while we work on it.
